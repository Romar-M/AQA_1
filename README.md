# AQA_1

Первая практическая по Python: отбор совершеннолетних пользователей с email.

Решение в `main.py` использует одно выражение list comprehension. Если возраст отсутствует, берётся 0. Отсутствующий или пустой email не проходит проверку.

Требуется Python 3. Внешние библиотеки не нужны.

```bash
python main.py
```

Результат:

```text
['Alice', 'Charlie']
```
